    كيف تتحول أشجار كثيرة إلى تنبؤ واحد؟

    Random Forest نموذج تجميعي: نبني أشجار قرار مختلفة على عينات Bootstrap تُسحب من بيانات التدريب مع الإرجاع، ونجرّب عند الانقسامات مجموعات فرعية عشوائية من المتغيرات. يسمح ذلك بتنويع الأشجار وتقليل تذبذب النموذج عند جمع توقعاتها.

    المفاهيم والمصطلحات الأساسية

    • Bootstrap: سحب n سجلًا من n سجلات مع الإرجاع؛ قد تتكرر السجلات وتُستبعد أخرى.
    • Feature subsampling: تجربة جزء عشوائي من المتغيرات في كل انقسام.
    • Voting: في التصنيف تختار الغابة الفئة صاحبة أكبر عدد أصوات.
    • OOB: أمثلة لم تدخل عينة Bootstrap الخاصة بشجرة معينة ويمكن الاستفادة منها في التقييم.

    مثال حسابي محلول خطوة بخطوة

    1. افترض خمس أشجار تعطي لمشروع جديد التنبؤات: خطر، آمن، خطر، خطر، آمن.
    2. الأصوات هي 3 «خطر» مقابل 2 «آمن»، لذلك نتيجة تصويت الأغلبية هي «خطر».
    3. نسبة الأصوات للخطر =3/5=0.60؛ هذه النسبة ليست بالضرورة احتمالًا معايرًا للخطر في الواقع.
    4. لو أضفنا شجرتين وصارت الأصوات 3 خطر و4 آمن، تتغير الفئة النهائية إلى آمن. لهذا فإن عدد الأشجار وطريقة تدريبها مؤثران.
    5. في مسائل الانحدار، عوضًا عن التصويت، نحسب متوسط قيم الأشجار؛ مثل 8 و10 و12 تصبح النتيجة 10.

    ماذا يحدث في التطبيق الحقيقي؟

    خطوات التدريب الحقيقية: لكل شجرة نسحب عينة Bootstrap، ثم ننمو الشجرة؛ عند كل عقدة نبحث عن أفضل تقسيم ضمن عدد محدود من المتغيرات المختارة عشوائيًا. بعد بناء عدة أشجار نستخدم التصويت أو المتوسط. قيّم Precision وRecall وF1 ومصفوفة الالتباس على بيانات اختبار منفصلة. ليست أهمية المتغيرات الناتجة من الغابة دائمًا تفسيرًا سببيًا.

    كيف تقرأ المختبر الحالي؟

    يعرض المختبر أصواتًا ثابتة توضيحية لأشجار افتراضية مع تغيير عددها؛ لا يقوم بتدريب أشجار حقيقية في المتصفح. مثال Python المرفق يستخدم RandomForestClassifier لتوضيح التدريب الفعلي.

    أخطاء شائعة

    • اعتبار نسبة الأصوات احتمالًا موثوق المعايرة دون اختبار.
    • افتراض أن زيادة الأشجار تحسن الأداء دائمًا بلا حدود.
    • الخلط بين مخطط التصويت التعليمي وتدريب غابة عشوائية كاملة.

    How many decision trees produce one prediction

    Random Forest is an ensemble method. Trees are fitted on bootstrap samples drawn with replacement, and candidate splitting features are randomized at nodes. This promotes diversity across trees and can reduce variance when their outputs are aggregated.

    Key terms and concepts

    • Bootstrap sample: draw n rows from n training records with replacement; duplicates and omissions occur.
    • Feature subsampling: consider a random subset of predictors at a split.
    • Voting: classification uses the class with most votes.
    • Out-of-bag (OOB): records absent from a particular tree's bootstrap sample can help evaluate it.

    Step-by-step worked numerical example

    1. Suppose five trees predict for one project: risk, safe, risk, risk, safe.
    2. There are three risk votes and two safe votes, so the majority-vote output is risk.
    3. Risk vote share =3/5=0.60; this is not automatically a well-calibrated real-world probability.
    4. If two additional trees vote safe, counts become three risk versus four safe and the output changes. Tree composition and ensemble size matter.
    5. For regression, average numeric tree predictions instead: 8, 10 and 12 yield a prediction of 10.

    What happens in the complete algorithm?

    Real training draws a bootstrap sample for each tree, grows splits while considering randomized feature subsets, then aggregates votes or means. Evaluate on held-out data with precision, recall, F1 and confusion matrices. Variable-importance measures from forests do not establish causal importance.

    How to interpret the existing interactive lab

    The widget displays predetermined votes from illustrative trees while allowing the ensemble size to change. It does not train a forest in the browser. The linked Python code demonstrates fitting a real RandomForestClassifier.

    Common mistakes

    • Equating raw vote share with calibrated probability.
    • Assuming ever-more trees always improve predictive quality.
    • Mistaking the vote demonstration for full Random Forest training.

    # Random Forest: illustrative scikit-learn example
from sklearn.ensemble import RandomForestClassifier
X = [[1,70],[2,82],[3,45],[4,91],[2,40],[5,98]]
risk = [0,0,1,1,1,1]
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X, risk)
print(model.predict([[3,60]]))
